# 中英界面切换

设置顶部提供“语言 / Language”：简体中文和 English。默认中文，保存为应用自己的 interfaceLanguage 偏好，更新和重启后保留。仅改变界面语言，不改变操作系统语言、OCR 识别语言、快捷键、文件名或目录。

共享规则是语言标识 zh-Hans/en、缺失或不合法值回退中文，以及同一处文案同时给出中英两版。macOS 使用 L(中文, English) 和语言变更通知，Windows 使用集中语言状态和 tr(中文, English)。这些函数只读本地偏好，不进行联网翻译；两种翻译靠近调用位置，减少平台专属错误文案的遗漏。

语言切换立即更新设置、菜单、悬浮球提示、截图工具栏、OCR 标题/状态和录屏来源/控制栏。刷新文字和布局，不销毁业务会话。OCR 编辑内容、截图选区、录屏来源与音频选择、录制时长和暂停状态保持；动态状态在更新后使用当前语言。系统原生窗口与底层系统错误按系统语言显示。

英文按钮按内容测量，避免中文固定宽度裁掉英文。保留稳定可访问性标识，测试不把翻译后的标签当作唯一动作身份。

验收覆盖：偏好持久化与错误值回退；设置两次切换；当前选区和 OCR 用户文本保持；中英工具栏尺寸；录屏状态保持；两端编译和安装包。没有真实 Windows 环境时，明确区分云端测试与实机验收。
