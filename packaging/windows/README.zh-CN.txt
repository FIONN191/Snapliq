Snapliq @VERSION@ — Windows 桌面截图与录屏工具
Capture. Record. Share.

支持系统
Windows 10 版本 2004（内部版本 19041）及以上、Windows 11，64 位 x64 电脑。
本包是独立桌面程序，不需要 Chrome、浏览器扩展、Node.js 或另外安装 Visual C++ 运行库。
Windows ARM64 模拟运行尚未完成验收。Windows N/KN 版需先从系统可选功能安装 Media Feature Pack
并重启后再启动；缺少媒体 DLL 时系统可能直接阻止启动，不一定能显示应用内提示。

安装与启动
安装版：运行 Snapliq-@VERSION@-windows-x64-development-setup.exe，按提示完成当前用户安装。
免安装版：先解压整个 ZIP 到固定文件夹，再双击 Snapliq.exe。不要从 ZIP 预览窗口直接运行。
安装版与免安装版使用相同的个人设置；不要同时运行两份 Snapliq。
当前为未签名开发版本。仅从自己的构建或项目提供的文件使用，可对照 SHA256SUMS.txt 校验文件。
源码与问题反馈：https://github.com/FIONN191/Snapliq

快速录制整个屏幕
1. 打开 Snapliq，确认系统托盘出现 Snapliq 图标。
2. 将鼠标移到要录制的显示器，按 Ctrl + Alt + R 开始录制该屏幕。
3. 切换到桌面、浏览器、办公软件等应用，屏幕上显示的普通内容会持续被录制。
4. 再按 Ctrl + Alt + R 停止；等待 MP4 封装完成和保存提示后再关闭应用或移动文件。
无需先指定保存文件。默认位置为当前用户“视频”文件夹内的 Snapliq 文件夹；
若之前在设置中指定了默认保存位置，则使用该位置。文件自动命名并处理重名。

屏幕、窗口与声音
从托盘菜单打开“屏幕录制”，可选择整块显示器或单个窗口，使用暂停、继续和停止。
要录下在多个应用之间切换的过程，请选择“屏幕”，不要只选择某个窗口。
系统声音与麦克风默认开启，后续会记住你主动关闭的选择。
麦克风需要有效输入设备，并在 Windows“设置 → 隐私和安全性（Windows 10 为隐私）→ 麦克风”
中允许桌面应用访问。请用实际试录检查输入设备、音量及 MP4 声音。
关闭设置窗口或退出 Chrome 不会停止正在进行的桌面录屏。
单次录制选择一个显示器或一个窗口；多显示器合并为一个视频及区域视频裁剪尚未提供。

系统捕获范围
录屏使用 Windows 原生系统捕获。桌面、普通应用窗口和屏幕上正常显示的内容均属于捕获目标。
DRM 受保护视频、主动禁止捕获的窗口、锁屏、UAC 安全桌面，以及部分独占全屏或特殊图形内容
可能不可用、显示黑屏或导致停止；本程序不会绕过这些系统限制。
录屏控制条和悬浮球会请求系统排除捕获；不支持排除时会隐藏，并可从托盘暂停或停止。

截图与悬浮球
默认截图快捷键 Ctrl + Alt + X；截图与录屏快捷键均可在软件设置中分别修改。
悬浮球左键截图、右键打开菜单；设置可调整边缘吸附、32–96 大小和位置锁定。
关闭设置窗口后仍常驻托盘；仅“退出应用”结束后台运行。

验收范围
构建流程检查原生编译、自动化测试、安装/卸载、版本和文件哈希。
这些检查不等于 Windows 10/11 实机的屏幕、声音、休眠、权限变化或混合 DPI 验收。
首次使用请先录制并播放一段短片，确认画面、系统声音、麦克风和保存位置。
