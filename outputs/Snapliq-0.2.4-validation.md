# Snapliq 0.2.4 — 悬浮球自定义验收

日期：2026-10-14。桌面功能增量，Chrome 开发与商店提交继续暂缓。

## 已实现

- macOS / Windows 原生设置新增「吸附屏幕边缘」、32–96 逻辑单位大小滑块（默认 48）和「锁定当前位置」。大小、品牌符号、圆形材质及录制状态标记同步缩放。
- 开启吸附时，拖动结束停靠最近的四边之一；关闭后保留自由位置。锁定防止拖动，但保留点击截图与右键菜单；锁定时的拖动尝试不会变成一次截图点击。右键可直接锁定/解锁。
- 锁定优先于吸附，单独解锁不会使自由位置跳到边缘。调整大小保留中心，在工作区边缘做必要的可见性修正。
- 保存偏好、所在显示器与位置；macOS 迁移旧的左右边缘/高度比例。隐藏或当日停用状态不因大小和锁定设置而被解除。
- 保持独立桌面窗口、应用生命周期与原有捕获排除策略，不新增浏览器依赖。应用标识和数据目录未修改。
