# Windows 全屏录制入口 · 0.2.5

2026-10-24。读取并执行本仓库 UI UX Pro Max 的 design-system（desktop screen recording utility native minimal monochrome status feedback）与 UX error/actionable feedback 查询。沿用 MASTER 原生桌面视觉、系统字体和黑白银灰，不采用搜索中网页营销模板。

- 录屏来源明确标为「整个屏幕」或「窗口」，默认选鼠标所在显示器。说明整个屏幕可覆盖桌面、浏览器及其他应用之间的切换，Chrome 无依赖。
- 保持系统声音与麦克风默认开启，显式用户选择继续持久化。无法捕获音频时明确设备/权限恢复方法，不静默假装已录音。
- 原生控件保留 Tab 焦点。状态为准备、录制、暂停、正在保存，对应真实状态；开始不弹提前保存对话框。
- 受保护内容只在简短说明中澄清；不承诺绕过系统捕获限制。
- 打开正在录制的控制条也需再次通过捕获排除检查，失败保持隐藏，通过托盘暂停/停止。
- 安装器和免安装包都包含中文使用说明及实际支持的系统版本，不让普通用户自行编译源码或下载 VC++ 运行库。
