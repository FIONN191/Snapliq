# 悬浮球自定义 · 0.2.4

2026-10-14。用户要求：可选边缘吸附、自定义大小、固定位置。沿用已确认的原生桌面架构。

实际沿用已安装并读取的 UI UX Pro Max Skill，执行 design-system 查询（desktop utility floating orb minimal monochrome native settings accessibility）及 UX 查询（drag slider keyboard feedback accessibility）。保留 MASTER 的黑白银灰、AppKit 原生玻璃兼容层与系统字体，舍弃查询中营销页面或网页专属布局建议。

- 设置新增“吸附屏幕边缘”“悬浮球大小”“锁定当前位置”。滑块有可见数值、可访问性名称，支持键盘调整，变化即时生效。
- 大小以系统逻辑单位计（macOS pt / Windows DIP），范围 32–96、默认48；符号、圆形材质和录制状态标记同步缩放，不机械扩大窗口而保留小图。
- 保留旧用户默认的吸附行为。吸附开启时拖动松手停靠最近的四边之一；关闭时保留自由位置，并限制在可见工作区内。
- 锁定当前位置用于避免误拖动，不阻止单击截图或右键菜单。锁定期间的拖拽尝试不触发截图。
- 锁定优先于吸附；锁定时调整大小保持中心位置（接近屏幕边界时做最小修正），切换吸附不让悬浮球跳走。
- 自由位置、大小和两个开关持久化。旧版边缘/垂直比例位置迁移到新坐标；显示器断开或布局变更后恢复到可见工作区。
- 设置调整不自动恢复已隐藏、停用或仅今天停用的悬浮球。菜单栏/托盘保留恢复入口。
- 继续使用真实桌面窗口。截图和录屏仍使用原有自身窗口排除策略，不新增浏览器依赖。
