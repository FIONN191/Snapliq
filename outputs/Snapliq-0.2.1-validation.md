# Snapliq 0.2.1 桌面开发验收
更新于 2026-09-09。用户明确选择继续桌面开发，暂缓 Chrome Web Store 提交；本轮没有上传或提交商店审核。

## 本轮变化
- SmartSelection 保留查询期间的最新鼠标位置，旧结果返回后自动处理最新请求，不再依赖下一次鼠标移动唤醒。
- AX 查询仍最多一个并发、启动间隔至少 100 ms；300 ms 缓存按进程与窗口边界共同隔离；候选去重，取消后不回调，权限关闭时回退窗口，排除自身进程。
- 截图工具栏按原生按钮 intrinsicContentSize 加左右各 16 pt 计算，本机由原先放置时的 382 pt 调整为 407 pt，保持屏边避让。
- 录屏控制条新增可访问标题、稳定标识、暂停/继续/停止并保存的名称与帮助文字；显式唤出可获得键盘焦点，Tab 顺序在暂停和停止间循环；封装时禁用重复停止。
- 构建默认输出到 outputs/builds/<版本>/Snapliq.app。打包时核验 App 版本与品牌配置一致，防止把旧二进制打成新版本包。
- 已授权的 outputs/candidate/Snapliq.app（0.2.0）及其交付包保留。Bundle ID、Chrome ID、数据目录保持不变。

### 最终 App 验收
| 检查 | 结果 |
|---|---|
| Chrome 完全退出后的 Command + X 截图 | 100/100 次；每次读取系统剪贴板真实 PNG，840×480 像素；每次检查 Chrome 主进程不在运行 |
| 关闭设置后快捷键、移动和缩放选区 | settings_closed/applicationContinues=true；重新快捷键截图，移动并缩放后图片为 900×540 像素 |
| Esc 取消后重新截图 | 再次进入截图并复制 840×480 PNG 通过；取消路径不写 session_finished，测试以随后成功截图确认恢复 |
| 桌面悬浮球 | 在当前实际位置 (1412,640)，48×48 pt，鼠标点击后唤醒；截取它原先所在的 136×136 px 区域，视觉检查没有本工具悬浮球 |
| 原生保存 | Command + S 保存到用户此前配置的磁盘文件夹；生成真实 840×480 PNG，48,234 字节 |
| Chrome 退出及设置关闭期间录屏 | 对最终 App 当前屏幕录制执行 Chrome 退出、关闭设置，然后成功暂停、继续、停止；桌面进程保持运行 |
| 录屏文件 | H.264，2940×1912；容器时长 38.496667 秒，18,521,956 字节；应用累计有效时间 38.477425 秒、1128 帧、报告 dropped=0；完整 ffmpeg 解码退出码 0 |
| 配套入口的本机注册 | Native Messaging manifest 更新到当前 0.2.1 包内 SnapliqBridge；扩展 ID 和主机名称不变，没有商店提交 |
| 测试清理 | 剪贴板恢复，测试画面进程退出，Chrome 重新打开，Snapliq 继续常驻 |

本段录屏未开启麦克风和系统声音，因此不能作为 0.2.1 音轨验收。录屏包含实际桌面画面，仅保存在本机，不纳入源代码或开发包。采样帧未见 Snapliq 控制条，但没有对本段视频执行逐帧遮挡比对；先前 0.2.0 在生成画面上的控制条/悬浮球排除验证仍仅作为历史基线。

自动化曾遇到窗口点击目标不稳定和等待取消日志的脚本错误；未将这些尝试计为通过。最终录屏验证通过明确的 AXPress 暂停/继续/停止标识及窗口 AXCloseButton，设置关闭以真实事件确认；仅后续成功完成的会话写入验收结果。

### 最终 App 性能（100 次）
设备：MacBook Air M2、16 GB；macOS 15.7.7 (24G720)；单内置显示器，1470×956 逻辑尺寸、2940×1912 捕获像素、60 Hz。100 次中不丢弃首个样本，每次执行真实系统键盘事件、框选及剪贴板读取。

| 测量区间 | P50 | P95 |
|---|---:|---:|
| Command + X 系统事件发送前 → 首次反馈提交 | 20.55 ms | 21.55 ms |
| Command + X 系统事件发送前 → 桌面底图就绪 | 69.54 ms | 73.01 ms |
| Command + X 系统事件发送前 → 可框选节点 | 147.86 ms | 265.85 ms |
| Enter 系统事件发送前 → PNG 写入剪贴板完成 | 113.87 ms | 120.22 ms |

起点是 CGEvent 发送前的单调时钟；反馈和可框选终点是应用提交/运行循环节点，**不是物理按键延迟、屏幕光子延迟或首帧真正呈现时间**。每轮底图就绪后才框选，不以空壳窗口冒充截图完成。原始样本与事件见 evidence/v0.2.1/capture-*.json*。

混合截图与录屏测试结束后的 vmmap 物理占用快照约 81.1 MiB，进程峰值 223.8 MiB。这是单次快照，不代表长期待机或录屏内存走势已经验收。旧版性能见 [0.2.0 报告](Snapliq-0.2.0-validation.md)，不与本轮样本合并。
